# The Timeline view is a pure component, and Runs poll with a browser-overridable interval

BIA-33 shows a Dry Run's result with the same view as a real Run, so the Timeline is a component (`ui/src/components/timeline/`) that takes the API's `timeline` array and an optional `dryRun` marker and fetches nothing; the Run screen owns the query. The view groups the flat entries by Step and `iteration_path` (indented by depth, since the API carries no nesting), lists each Attempt with its error message always visible, and keeps inputs, Outputs and error details behind closed disclosures that format their JSON only when opened and cut it at 4,000 characters until asked, so a large Output cannot freeze the page. Status refreshes by polling (SSE is BIA-88): an active Run, or a list showing one, refetches every 2 seconds and stops once the Run has ended; the interval can be overridden per browser with `localStorage["bia.pollIntervalMs"]` so end-to-end tests do not wait, without a config field or build flag that would have to be supported once SSE lands. The API never returns a Secret's value; the UI only labels Templates reading `secrets` and `[REDACTED]` markers as "secret placeholder", and never tries to reveal or reconstruct them. The Runs list pages by keyset (`next_after`) behind a "Load more" button, and its filters live in the URL so a filtered list is linkable.
