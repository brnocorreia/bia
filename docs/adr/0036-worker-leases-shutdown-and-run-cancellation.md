# Workers heartbeat their Leases, release them on shutdown, and cancel Runs through a flag and a notification

A Worker runs each claimed Job as a tokio task, up to a configured concurrency, so one process overlaps many Actions that mostly wait on the network. It claims when a slot is free, when `LISTEN/NOTIFY` says a Job became claimable, and on a poll timer, because delayed Jobs falling due and expired Leases notify nothing (ADR-0031). Next to every Job runs a heartbeat that extends the Lease each third of its duration, timed from the Lease rather than from the previous beat, so Leases stay short (30s by default) and bound how long a crashed Worker's Jobs stay stuck, while an Attempt may run as long as its timeout. On SIGTERM or SIGINT the Worker stops claiming, gives in-flight Jobs a grace period (20s by default, inside the usual 30s an orchestrator waits before SIGKILL), then drops the remaining tasks, which rolls back their uncommitted transitions, and releases their Leases. A released Lease uses up the Attempt, because the attempt counter is the fencing token and must never repeat, and it notifies `bia_jobs`, so another Worker resumes the Job at once instead of after the Lease expires; the Step then re-runs with the same Idempotency Key, as after a crash (ADR-0010). Cancelling a Run sets `cancel_requested_at` on it, which a trigger announces on `bia_run_cancels` with the Run id; the Worker holding that Run's Job fires the Run's cancellation token, which reaches the Action as a child token, and each heartbeat re-reads the flag in case the notification was lost while the listener reconnected. A notification alone could be lost and polling alone would make cancellation as slow as the heartbeat, so both are used. A Run waiting on a delayed Job, such as a sleep, has that Job brought forward to the cancel time, and one with no live Job gets a new one, so it ends promptly rather than at its wake time. However it is reached, the interpreter ends the Run `cancelled` at its next transition with its Cursor where it was, and records exactly one `cancelled` Timeline entry: the Attempt that was cut short, or a Run-level entry when none was in flight (amending ADR-0033).
